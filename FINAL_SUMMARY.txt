🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   cd appscript
   npm install
   cd client && npm install

2. SETUP DATABASE
   createdb lms_db
   psql -U postgres -d lms_db -f schema.sql

3. CONFIGURE ENVIRONMENT
   copy .env.example .env (edit dengan credentials Anda)
   cd client && copy .env.example .env

4. RUN APPLICATION
   Terminal 1: npm run dev (backend port 5000)
   Terminal 2: cd client && npm run dev (frontend port 5173)

5. ACCESS APPLICATION
   Frontend: http://localhost:5173
   Backend API: http://localhost:5000
